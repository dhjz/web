# PDF 工作台 · vuepdf-new

任务式 PDF 处理工作台，桌面软件风格交互。全部在浏览器本地完成，文件不上传。

```bash
cd vuepdf-new && python3 -m http.server 8080
# 访问 http://localhost:8080/
```

## 页面结构

- **左侧 60%**
  - 上半：文件列表 —— 支持上传、整窗拖拽、Ctrl+V 粘贴；分类下拉、搜索、名称/大小/时间排序、全选/单选
  - 下半：工具列表 —— 17 个工具，选中文件后才可点击，点击弹出参数设置
- **右侧 40%**
  - 任务列表：支持编辑、删除、开始、全部开始；每个任务有进度条
  - 完成后出现「详情」按钮，弹窗查看输出列表并下载

## 交互细节

- 文件列表和任务仅存在于当前页面；刷新页面会清空，不需要重新添加提示
- 任务执行失败时展示错误原因，可编辑后重新运行
- 输出文件自动命名为 `源文件名_工具.扩展名`，合并任务输出 `合并.pdf`；多文件任务逐个处理并输出多个结果
- 上传框整块可点击，文件选择器限制为 PDF 和常见图片格式；拖拽、整窗粘贴也会过滤掉不支持的文件，并提示跳过数量。
- 深色模式切换、状态栏统计、Esc 关闭弹窗、响应式窄屏回退

## 参数处理

- PDF 转图片：支持 DPI（预设或自定义，自定义值为滑块+输入）、页码范围（留空=全部；支持 `1, 3-5, odd, even, all`）、固定输出宽度（0 按 DPI 自动，填写数值则在 DPI 渲染后高质量等比例缩放到该宽度）、JPG/PNG、JPG 质量数值显示、JPG 可选 jSquash 编码（与 PNG 的 UPNG.js 一样用勾选框切换）、ZIP/多文件输出
- 压缩：目标清晰度（DPI）/ JPEG 质量直接作为压缩参数并真正参与压缩；DPI 按页面物理尺寸换算图片像素，A4 约 96 DPI 等于 WPS 100% 屏幕显示，200 DPI 约等于原始扫描，只缩小超过目标的图片、不放大；勾选「强制栅格化所有页面」时 DPI 直接决定每页渲染比例；日志会打印原页面 pt 尺寸、目标 DPI、最终比例和输出像素；编码器选项会落到实际处理；不勾选栅格化时只压缩 PDF 内嵌图片，失败也保留原文件，绝不自动栅格化
- 提取图片：使用 pdf.js 扫描 PDF 内嵌图像，支持 PNG/JPG、JPG 质量、JPG 可选 jSquash 编码（勾选框切换）、PNG 的 UPNG.js 压缩、ZIP/多文件输出；修复、灰度等工具会消费密码参数
- 添加页码：按字体实测宽度定位，六种位置都按文字边界计算，不会偏轴
- 水印：参数弹窗内实时预览使用与导出一致的旋转方向，并保持原有平铺间距语义；不透明度、字号、旋转角度、重复间距支持滑块拖动与数值输入，修改文字/颜色/透明度/字号/旋转/平铺/间距后立即刷新
- 重排 PDF：页序按输入顺序逐项解析，必须包含全部页面且不重复（如 `3,1,2`）；留空则保持原序
- 拆分 PDF：页码范围支持 `odd`/`even`/`all`（也可写 `奇数页`/`偶数页`/`全部`）；支持用英文 `;` 或中文 `；` 分隔成多组（如 `1,2;2-5, 10；3,4,5`），每组输出一个 PDF；「单个文档」模式在详情弹窗逐项预览/下载，「多个文件」模式将每个分号组合并成的 PDF 打进一个 ZIP（不会逐页输出重复文件）。不含分号时逐页 ZIP 内的文件名保留源文件名，并按文档总页数补零（30 页文档输出 `报告_第01页.pdf`…`报告_第30页.pdf`；分多组输出 `报告_拆分-01.pdf`…）
- 详情弹窗图片网格固定一行 4 张，预览按 3:4 比例限制高度；图片大小旁显示输出宽高（分辨率）
- 图片预览弹窗：滚轮以鼠标位置为中心缩放，按住图片拖动可平移；`1:1` 按钮在适合屏幕与 100% 原尺寸间切换（以中心为锚点），关闭后重开恢复适合屏幕

文件列表顶部新增「从 HTTP 加载 PDF（二进制）」入口：调用 `PdfCore.readHttpPdf(url)`，执行 `fetch -> arrayBuffer -> Uint8Array`，不转 Data URL；跨域地址需要目标服务允许 CORS。

资源复用 `vuepdf/static/` 的 vue3 / pdf-lib / jszip / pdfjs / cmaps。
中文字体使用本目录 `static/fonts/AlibabaPuHuiTi.ttf`，字体引擎为 `static/fontkit.umd.min.js`；中文水印、页码、签名会按需嵌入字体子集，WOFF2 不落地。

jSquash MozJPEG 编码器已内置在 `static/jsquash/`，按相对路径按需加载；加载失败时 JPEG 回退 Canvas。PNG 仅使用 UPNG.js，不依赖外网 CDN。

## 子路径部署（Nginx location /pdf/）

页面内所有 JS / MJS / worker / cmaps 均使用相对路径加载，可直接放在任意子路径下。
例如部署到 `/pdf/` 时，将本目录内容上传到 nginx 的 `alias /path/to/vuepdf-new/;` 对应目录，访问 `https://example.com/pdf/` 即可，无需改动代码中的根路径。
