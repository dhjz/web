1. 直接传入 HTML 代码 excel2md.html()

粘网页 / Word / Excel 复制出来的 HTML（整页也行，只取 table）。表头相同的表格自动合并；输出格式在顶部全局选：Markdown（标题转 # 只在这一种）/ 原始 HTML（样式全留）/ 净化 HTML（只留结构，标题仍是 <hN>）。

2. 监听粘贴事件 excel2md.bind()

在这个框里 Ctrl+V：Excel / Word / 网页复制的表格、以及 HTML 源码文本都会被拦下，只输出到结果区，框里不落原文。普通文字照常粘贴。

粘贴后转成
点这里，然后 Ctrl+V…

输出 · Markdown（可编辑）

3. 拖入本地文件 / 整页 HTML drag & drop

把 .html / .htm / .mht / .doc / .md / .txt / .csv / .tsv 拖进来（或点一下选文件）。Excel / Word 另存为「网页(.html)」后直接拖最省事，样式会完整保留到原始 HTML 输出里。

从 Excel 直接复制常常是 TSV，从表格工具复制可能是 Markdown 源码。库会自动识别：html / markdown / tsv / csv。
